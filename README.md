                                 Pontos Importantes:
       1. Iniciar, dentro da pasta "App", o arquivo server.js por "node server.js" (ou simplismente "npm start")
       2. Tecnologias usadas: express, ejs, bcript, sequelize (Mysql), Bootstrap
       3. Separação do trabalho: 
                   - Estrutura MVC completa: Mateus B. 50%
                   - Integração com Banco de Dados: Isabelle N. 20%
                   - Sistema de segurança, 'sessions' e lógica do  front_end: Luis Felipe D. 15%
                   - Estilização das views por Frameworks (Bootstrap): Luis G. Moraes  15%          
       4. Para usar o banco de dados: 
                   - Tenha o MySQL instalado no seu computador 
                   - Crie o Banco de dados com o nome no documento "/Banco_dados/integer.js"
                   - coloque sua senha dentro desse arquivo ou use a senha padrão
                   - Está tudo pronto!
       5. Para confirmar a criação de uma nova entidade (Seja Animal, Responsável, Veterinário etc.)
                   - Saia da área de edição do bloco de formulário
                   - Caso necessário, atualize a página (Estamos tentando arrumar isso)
